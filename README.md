# 유니폼 피팅 랩 (Uniform Fitting Lab)

의상 디자인과 색상을 팔레트에서 골라 마네킹에 바로 입혀 보는 **반응형 가상 피팅 시뮬레이터**입니다.
간호·의료 유니폼(근무복, 스크럽, 가운)을 중심으로 일반 의상도 시험할 수 있습니다.

## 실행
설치 없이 `index.html`을 브라우저로 열면 됩니다. 단일 파일이며 외부 라이브러리를 쓰지 않습니다.

## 기능
- 상의 5종(V넥 스크럽, 차이나칼라 튜닉, 셔츠, 폴로, 라운드 티), 하의 4종, 아우터 3종(+없음), 신발 3종
- 색상 팔레트 4그룹(의료 유니폼 / 뉴트럴 / 파스텔 / 비비드), 컬러 피커, HEX 입력
- 본판과 포인트(파이핑·칼라·단추·밑창) 색 분리
- 패턴: 솔리드, 핀스트라이프, 깅엄 체크, 도트
- 소품: 명찰, 사원증, 청진기, 수술모
- 마네킹 톤 5종, 체형 3종
- 예시 코디 6종, 실행 취소, 랜덤 코디, 초기화
- 디자인 사양서(색상명·HEX) 표와 텍스트 복사
- 코디 저장·불러오기(브라우저 localStorage)

## 수정·확장 방법
설계 기준은 [`PROMPT.md`](PROMPT.md)에 있습니다. `index.html` 안의 데이터 객체만 고치면 기능이 늘어납니다.

| 바꾸고 싶은 것 | 수정 위치 |
|---|---|
| 새 디자인 추가 | `STYLES.top / bottom / outer / shoes` 배열에 `{ id, name, note, draw }` 추가 |
| 색상 추가 | `PALETTE` 배열 |
| 패턴 추가 | `PATTERNS` 배열 + `patternDef()` |
| 예시 코디 추가 | `PRESETS` 배열 |
| 소품 추가 | `ACCS` 배열 + `accSvg()` |
