# 단체복 피팅 랩 (Group Apparel Fitting Lab)

일반인 대상 **단체복 상의**를 디자인해 마네킹에 바로 입혀 보는 반응형 가상 피팅 시뮬레이터입니다.
반티, 동아리 후드, 워크숍 카라티, 응원 야구점퍼 같은 시안을 주문 전에 비교할 수 있습니다.

## 실행
설치 없이 `index.html`을 브라우저로 열면 됩니다. 단일 파일이며 외부 라이브러리를 쓰지 않습니다.

## 기능
- 상의 스타일 14종 (5개 계열)
  - 티셔츠: 라운드 반팔 · 라운드 긴팔 · V넥 반팔 · 나그랑 티
  - 카라티: 반팔 · 긴팔
  - 맨투맨·후드: 맨투맨 · 반집업 · 후드티 · 후드집업
  - 집업·아우터: 트레이닝 저지 · 바람막이 · 야구점퍼
  - 조끼: 단체 조끼
- 배색 3영역: 몸판 / 소매 / 배색(립·칼라·지퍼·후드 안감 등)
- 팔레트 4그룹(베이직·팀 컬러·파스텔·어스톤), 컬러 피커, HEX 입력
- 원단 패턴: 솔리드 · 보더 스트라이프 · 깅엄 체크 · 도트
- 프린트: 메인·보조 문구, 위치(왼쪽 가슴/가슴 중앙), 서체 4종, 색상
- 예시 디자인 8종, 실행 취소, 랜덤, 초기화
- 디자인 사양서 표와 텍스트 복사, 디자인 저장·불러오기(브라우저 localStorage)

## 수정·확장 방법
설계 기준은 [`PROMPT.md`](PROMPT.md)에 있습니다. `index.html` 안의 데이터 객체만 고치면 기능이 늘어납니다.

| 바꾸고 싶은 것 | 수정 위치 |
|---|---|
| 새 상의 스타일 | `STYLES` 배열에 `{ id, group, name, note, trimNote, draw }` 추가 |
| 색상 | `PALETTE` 배열 |
| 패턴 | `PATTERNS` 배열 + `patternDef()` |
| 프린트 서체 | `FONTS` 객체 + Google Fonts 링크 |
| 예시 디자인 | `PRESETS` 배열 |
